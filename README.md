# מחליף הטפטים

אפליקציית Android ב-Kotlin וב-Jetpack Compose.

## תכונות
- טפטים מובנים.
- הוספת תמונות מהטלפון.
- בחירת מספר טפטים.
- החלפה אוטומטית לפי דקות, שעות או ימים.
- מסך בית, מסך נעילה או שניהם.
- שמירת הגדרות מקומית.
- תזמון מחדש לאחר אתחול המכשיר.

## בנייה
פתח את המאגר ב-Android Studio, בצע Gradle Sync ובחר:
Build > Build APK(s)

קובץ ה-debug יופיע בדרך כלל ב:
app/build/outputs/apk/debug/app-debug.apk
